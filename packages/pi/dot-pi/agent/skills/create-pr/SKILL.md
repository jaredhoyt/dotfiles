# Create Pull Request

## Instructions

1. Load and follow the global [PR baseline](../pr-baseline/SKILL.md).
2. If the current project provides `.pi/create-pr.md`, load and follow it. This optional project-local file holds project-specific PR rules; its rules supplement the global baseline and take precedence when they conflict.
3. Draft the PR title, description, technical details, and QA instructions, then ask for approval before creating or updating the PR.
4. When the request also includes committing changes, follow the `create-commit` skill first; commit before beginning this PR workflow.
